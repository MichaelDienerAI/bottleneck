Run `node src/ledger.js --report`.

Then answer four questions in order, briefly, using only ledger data:

1. **Where did work pile up?** Which stage held the most unfinished items at week's end? That stage, not your intuition, is the current bottleneck. If it moved, say so plainly.
2. **Signal or noise?** Apply the Deming rules. Fewer than twenty outreaches on one narrative is not a sample, so any strategy change proposed before that threshold is tampering. Say so and refuse it.
3. **Fitness.** Report weekly process fitness, the sum of 2^stage across all rows. Compare to the prior three weeks as a run chart in text. Response counts are noise. Stage depth is the signal.
4. **Abandon list.** Name what stops. A review that ends without a cut has decided nothing.

State the constraint for the coming week in one sentence, with the ledger evidence behind it.
